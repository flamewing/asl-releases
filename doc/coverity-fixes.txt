Sixth batch: integer-to-floating assignment semantics

914439, tempresult.c:TempResultToFloat
  Convert into a local as_float_t before assigning the floating union
  member. Integer and floating objects overlap but have incompatible
  types, violating C11 6.5.16.1 paragraph 3. RHS-before-store sequencing
  does not remove that additional constraint. This corrects the earlier
  review assessment. Preserve the AS_HAS128 QuadInt cast and metadata.
  Source: https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf

Validation: the production-type tempresult_float test covers integer
conversion and metadata, unchanged floats including negative zero/NaN,
and unsupported types using the real string cleanup implementation.
All 337 tests passed with embedded and external catalogs. Closure of
914439 is awaiting the next Coverity scan; no triage state was changed.
Separately compiling the full production source before/after at -O3
produced identical TempResultToFloat function assembly with both GCC
and Clang in the local default configuration.
