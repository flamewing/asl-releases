915444: INTEGER_OVERFLOW, code96c141.c, DecodeImm
Recommended classification: False Positive (argument-count correlation).

ImmOrder.Default == -1 marks an instruction with a required immediate.
DecodeImm then calls ChkArgCnt(1, 1). ChkArgCntPos delegates to
ChkArgCntExtPos, which returns False for ArgCnt == 0, whether or not the
bracket check also rejects the input. The reported path requires this
check to return True and then ArgCnt == 0; that path is infeasible.
The assignment to Word only sees the nonnegative defaults: EI uses 0
and SWI uses 7. LDF uses -1 and requires its explicit argument.

Regression t_900imm checks rejection of missing LDF arguments in both
minimum and maximum modes, the EI/SWI defaults, explicit immediate
encodings, and the maximum-mode LDF range boundary.

915445: STRING_NULL, as.c, assemble_core version banner
Recommended classification: False Positive / Modeling Required.

Tmp is a String, a char[STRINGSIZE] with default capacity 1024. The call
passes sizeof(Tmp). Expanded events show that the displayed 1 comes from
the literal-character append's byte count, not from sizeof(Tmp).
as_snprintf clears the destination and calls as_vsnprcatf. Formatting
uses limit_minus_one to reserve a terminator byte for each append,
including literal characters, substitutions, and padding. vsprcatf_core
writes that terminator after processing the format. The destination is
therefore terminated even when output is truncated. Expanded events take
dest_remlen > 0 as false at the final terminator: an infeasible branch,
because the initially positive capacity stays positive after each bounded
append, including padding. They also take a positive-width branch for the
literal append, although the first literal has reset width 0 and count 1.
A zero-capacity
call intentionally writes nothing, but the banner call has positive
capacity. Investigate the analyzer's helper summaries and lost reserved-NUL
invariant; do not change its project-specific return/conversion semantics
to libc semantics or suppress all string diagnostics.
